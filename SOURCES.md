# Quellen-Whitelist

Nur Quellen nutzen, deren **Nutzungsbedingungen** das automatische Abrufen (RSS/API) erlauben. Feeds hier dokumentieren; Änderungen mit Datum vermerken.

## Kriterien

- Bevorzugt: **offizielle RSS-Feeds** von Medien und Behörden  
- Keine Paywall-Umgehung; keine ToS-Verletzungen  
- Pro Feed: URL, Sprache, geografischer Fokus, Notizen
